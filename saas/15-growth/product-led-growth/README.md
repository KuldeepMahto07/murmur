# Product-led growth

**Status: Not started (plan written).** Part of [15 · Growth](../README.md) in the [Murmur SaaS plan](../../README.md).

- **Free tier is the acquisition engine:** unlimited 30-minute files and all exports, so students adopt it freely and bring it into their labs.
- **In-product expansion paths:**
  1. Length gate → Pro.
  2. "Share with your lab" → Team server trial (one machine in the lab, browser access for everyone, which reuses today's web UI).
  3. The 2-device limit → extra licence.
- **Self-serve everything:** checkout, licence, invoices and PO, with no sales calls under $2.5k.
- **Measure:** the time from install to first value (target: under 10 minutes including the model download).
