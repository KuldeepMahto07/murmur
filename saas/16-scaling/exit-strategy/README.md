# Exit strategy

**Status: Not started (plan written).** Part of [16 · Scaling](../README.md) in the [Murmur SaaS plan](../../README.md).

**Options (none needed; keep them open):**
1. **Lifestyle business:** profitable and run by a small team (the default path for this market size, see [01-idea/market-research](../../01-idea/market-research/)).
2. **Acquisition by an adjacent vendor:** QDA software (NVivo/Lumivero, ATLAS.ti, MAXQDA), privacy-focused productivity suites, or a hardware vendor's "AI PC" software portfolio.
3. **Micro-SaaS marketplace sale** (Acquire.com and similar) once revenue is stable for 12+ months.

**Keep exit-ready:** clean accounts, recurring revenue separated from one-time revenue, IP ownership clear (all code original; models used under their licences: Whisper MIT, pyannote MIT with gated weights, SpeechBrain Apache-2.0, Argos MIT), documented systems, and no single-customer dependency.
