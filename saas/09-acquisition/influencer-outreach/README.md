# Influencer outreach

**Status: Not started (plan written).** Part of [09 · Acquisition](../README.md) in the [Murmur SaaS plan](../../README.md).

- **Who:** academic-productivity YouTubers (PhD workflow, Zotero/Obsidian creators), qualitative-methods educators, and privacy-tech reviewers.
- **Offer:** a free Pro licence plus an affiliate code ([affiliate-marketing](../affiliate-marketing/)), and no script requirements. Ask them to try it on a real (non-sensitive) recording.
- **Shortlist:** 20 creators in a sheet with audience size, niche and contact; message 5 a week.
- **Disclosure:** require #ad / "sponsored" labelling per FTC/ASA rules.
