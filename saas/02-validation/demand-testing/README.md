**Status: Not started (plan written).** Part of [02 · Validation](../README.md) in the [Murmur SaaS plan](../../README.md).

| Test | Signal | Threshold |
|---|---|---|
| Search demand | Monthly volume for "offline transcription windows", "local whisper app windows", "transcribe interviews without uploading" (Google Keyword Planner / Ahrefs free tools) | Combined ≥ 3k/mo |
| Community pull | Upvotes and comments on a "show and tell" post with the demo GIF | ≥ 50 upvotes or ≥ 20 "where can I get it" replies |
| GitHub interest | Stars on the repo if open-sourced (see the [10-distribution](../../10-distribution/) open-core decision) | ≥ 200 in the first month |
| Download intent | Clicks on a "Download for Windows (beta)" button that leads to the waitlist | ≥ 15% of visitors |
