# SaaS and app marketplaces

| Marketplace | Fit | Action |
|---|---|---|
| Microsoft Store (MSIX) | High: trusted install, auto-update, no SmartScreen issue | Package v1.0 as MSIX; Store takes 15% (or 0% with own commerce for non-games) |
| winget | High for tech-savvy users | Submit a manifest after the signed release |
| Setapp-like bundles for Windows | Low (none dominant) | Skip |
| AppSumo (lifetime deal) | Medium: cash and users, but discount-hunters | Consider once, capped at 500 codes, after v1.0 is stable |
