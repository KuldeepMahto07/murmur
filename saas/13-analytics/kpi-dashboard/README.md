# KPI dashboard

**Status: Not started (plan written).** Part of [13 · Analytics](../README.md) in the [Murmur SaaS plan](../../README.md).

| KPI | Definition | Target (month 6 after launch) |
|---|---|---|
| Weekly active installs | ≥ 1 transcript / week (opt-in sample, scaled) | 1,500 |
| Activation rate | first transcript ≤ 24 h / installs | ≥ 60% |
| Free → Pro conversion | licences / activated users (90-day window) | ≥ 5% |
| Revenue | licences + Team ARR, monthly | $5k / month |
| Refund rate | refunds / sales | < 5% |
| Support load | tickets / 100 active installs / week | < 2 |

**Format:** one page (Google Sheet, or Metabase on the D1/DuckDB export). Update weekly with dated notes on what moved and why.
