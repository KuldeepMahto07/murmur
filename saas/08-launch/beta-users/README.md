# Beta users

**Status: Not started (plan written).** Part of [08 · Launch](../README.md) in the [Murmur SaaS plan](../../README.md).

- **Source:** waitlist responders who said "Windows + NVIDIA" and "research/journalism".
- **Size:** 30 (see [07-testing/beta-testing](../../07-testing/beta-testing/) for the protocol).
- **Give:** a free Pro licence for life, in exchange for 3 transcripts' worth of feedback and a 15-minute call.
- **Channel:** a private Discord or GitHub Discussions category, plus one email a week.
- **Measure:** install success, time to first transcript, corrections per 10 minutes, NPS question at day 14.
