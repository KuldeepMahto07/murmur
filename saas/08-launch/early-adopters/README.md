# Early adopters

**Status: Not started (plan written).** Part of [08 · Launch](../README.md) in the [Murmur SaaS plan](../../README.md).

- **Founding licence:** $29 (40% off the $49 price), first 200 buyers, with the name on a "founders" page if they opt in.
- **Who:** waitlist + interviewees + beta users' colleagues (ask each beta user for 2 intros).
- **Department pilots:** 3 university departments at $199 for 5 seats. Supervisors are the buyer; students are the users.
- **Feedback loop:** monthly "office hours" call; a public roadmap board (GitHub Projects) so early adopters can vote.
