# Enterprise deals

**Targets:** university faculties or site licences, law firms, HR consultancies, public-sector bodies with data-residency rules.

**What they'll ask for (build checklist):**
- [ ] Security questionnaire answers (architecture: everything local; no data processor relationship). The answer is "we never receive your data".
- [ ] Silent install (MSI), group-policy settings (models path, disable link import).
- [ ] SSO for the Team server (OIDC/SAML), audit log, data retention settings.
- [ ] Invoice/PO billing, W-9/vendor forms, an accessibility statement (VPAT).
- [ ] Support SLA.

**Pricing:** site licence from $2,500 a year (unlimited seats at one institution, Team servers included).
