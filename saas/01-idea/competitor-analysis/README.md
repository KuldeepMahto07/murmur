## Comparison grid (third-party 2026 pricing, see sources; verify before quoting)
| Product | Where it runs | Price | Speakers | Strength | Gap Murmur targets |
|---|---|---|---|---|---|
| TurboScribe | Cloud | Free 3 files/day; $10–20/mo unlimited | ✓ | Price and volume | Audio leaves the device |
| Otter.ai | Cloud | Free 300 min; Pro $16.99/mo | ✓ | Live meetings, bots | Cloud only, minute caps |
| Rev | Cloud | AI $0.25/min; human about $1.25–1.99/min | ✓ | Human accuracy option | Cost, cloud |
| Descript | Cloud + desktop | about $12–24/mo | ✓ | Edit video by editing text | Overkill for researchers, cloud transcription |
| Sonix / Happy Scribe | Cloud | about $10/h; €17/mo | ✓ | Multilingual subtitles | Cloud, per-hour cost |
| MacWhisper | **Local**, macOS | One-time license (price unverified) | Partial | Local, polished | **macOS only** |
| Buzz | Local, cross-platform, OSS | Free | ✗ | Free | No speakers, basic editor |

## Murmur's position
Local like MacWhisper, on **Windows with an NVIDIA GPU**, with speaker labels, an editor, 7 export formats and offline translation. That combination is the gap.
