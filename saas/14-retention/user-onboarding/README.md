# User onboarding

**Status: Not started (plan written).** Part of [14 · Retention](../README.md) in the [Murmur SaaS plan](../../README.md).

**First-run wizard (v0.2):**
1. **Hardware check:** "NVIDIA GTX 1650 Ti found, 4 GB → Precise mode available". Or for CPU-only: "Steady mode recommended; a 1-hour file takes about X min."
2. **Model download** with progress and size. Download `small` now; offer `large-v3-turbo` in the background.
3. **Speakers:** "Want better speaker labels? Connect a free Hugging Face token (2 minutes)" → guided steps → test button.
4. **Try the sample:** a 42-second two-voice demo file, so the first success happens in under a minute even before the user's own file.
5. **Privacy promise + analytics opt-in** (off by default).

**Success metric:** ≥ 60% of installs complete a transcript of their own file within 24 h.
