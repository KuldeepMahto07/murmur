# Sales funnel

**Status: Not started.** Part of [11 · Conversion](../README.md) in the [Harbor SaaS plan](../../README.md).

```
Store listing / SEO page / video
        ↓  (install: free app + extension)
First successful fast download  ← the "aha" moment (show speed and the verified badge)
        ↓
Hits a Pro-gated feature (2nd queue, quota, site grabber, proxy) or the 14-day Pro trial ends
        ↓
Upgrade dialog → checkout (merchant of record) → licence key pasted in the app
```

**Instrument it, opt-in only:** install → first download → first Pro prompt → checkout opened → purchase. See [13-analytics](../../13-analytics/funnel-analysis/README.md).
