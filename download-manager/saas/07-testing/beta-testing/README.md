# Beta testing

**Status: Not started.** Part of [07 · Testing](../README.md) in the [Harbor SaaS plan](../../README.md).

## Plan
- **Who:** 30 to 50 testers from the [waitlist](../../02-validation/waitlist/README.md), mixing Windows 10 and 11, Chrome and Edge, and fast and slow connections.
- **Build:** a signed installer, plus the extension as an unlisted Chrome Web Store item.
- **Duration:** 2 weeks.
- **Feedback:**
  - An in-app "Report a problem" link to a GitHub issue template (version, OS, log tail).
  - A weekly 5-question form: what broke, what was slow, what was missing, and whether they'd pay.
- **Exit criteria:**
  - No data-loss bugs.
  - Crash-free on 95% of sessions.
  - At least 40% of testers say "very disappointed" if Harbor went away (the Sean Ellis product-market-fit test).
