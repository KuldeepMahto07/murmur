# Product led growth

**Status: Not started.** Part of [15 · Growth](../README.md) in the [Harbor SaaS plan](../../README.md).

- **Free that's actually good:** the speed, resume and verification are free, which drives word of mouth.
- **Visible value:** the details pane shows "Saved you X minutes vs. a single connection" (estimated from the measured segment speeds). Users can screenshot and share it.
- **Shareable verification:** a "Copy verification report" button gives the file name, size, SHA-256 and source host, which is useful in forums when sharing large files.
- **The extension as a growth loop:** each install shows up in its store's install count and ratings. Ask for a rating after the 5th successful video download, and only then.
