# Viral loops

**Status: Not started.** Part of [15 · Growth](../README.md) in the [Harbor SaaS plan](../../README.md).

Download managers aren't naturally viral, so manufacture light loops:
1. **Verification report loop:** a user shares a SHA-256 report, other people see "verified with Harbor", some install it.
2. **"Download with Harbor" button:** site owners (open-source projects, ISO mirrors) embed a `fetchline://add?url=…&sha256=…` button. Users without Harbor get a landing page.
3. **Tutorial creators:** see [influencer-outreach](../../09-acquisition/influencer-outreach/README.md). Their videos keep bringing in users long after.

**Measure** the viral coefficient: new installs that came from a referral link or a `fetchline://` landing page, divided by active installs.
