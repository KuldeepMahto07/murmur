# Feature adoption

**Status: Not started.** Part of [14 · Retention](../README.md) in the [Harbor SaaS plan](../../README.md).

| Feature | Nudge to discover it |
|---|---|
| Video button | Onboarding step 2, plus a toast the first time media is detected on a page |
| Expected checksum | When the URL is an `.iso` or `.zip` and the page lists a SHA-256, suggest pasting it |
| Scheduler | After 3 downloads larger than 1 GB: "Schedule big downloads for tonight?" |
| Speed limit | When the user's other apps are busy (a long download over 80% of the line): suggest a cap |
| Categories and folders | After 10 downloads of mixed types |

Track adoption with the opt-in events. A feature under 10% adoption after 60 days gets better placement or gets cut.
