# UI design

**Status: Done.** Part of [04 · Design](../README.md) in the [Harbor SaaS plan](../../README.md).

## Built
- **Style:** dark and light themes with a teal-to-indigo gradient accent. The look is original and doesn't reuse IDM's artwork or layout skin.
- **Logo:** `ui/logo.svg`. Extension icons are exported at 16, 32, 48 and 128 px in `extension/icons/`.
- **Where it was checked:** in the browser pane (main window) and in headless Edge screenshots (video overlay menu).
