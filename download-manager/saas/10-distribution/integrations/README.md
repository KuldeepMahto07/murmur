# Integrations

**Status: In progress.** Part of [10 · Distribution](../README.md) in the [Harbor SaaS plan](../../README.md).

Integrations that also bring users in:
- ✅ **Chrome / Edge extension:** the store listing is a discovery channel in its own right.
- ✅ **AB DM hand-off:** appears in searches like "AB download manager extension video".
- ⏳ **Firefox add-on:** reaches privacy-minded users.
- ⏳ **Command line:** `fetchline add <url>`, mirroring IDM's `/d /p /f /a` flags, for scripters and other apps.
- ⏳ **"Open with Harbor" protocol handler** (`fetchline://add?url=…`) so websites can offer a direct button.
