# A/B testing

**Status: Not started.** Part of [13 · Analytics](../README.md) in the [Fetchline SaaS plan](../../README.md).

**Where it's possible:**
- **Website hero copy and pricing page:** Plausible goals plus a split URL. Run each test for at least 2 weeks or 1,000 visitors.
- **Store listing:** title and screenshots, by swapping and measuring week over week (the stores don't offer native A/B tests).
- **In-app upsell copy:** randomise on the install ID among opted-in users only.

**First 3 tests:**
1. "Faster downloads" vs. "Verified, crash-proof downloads" as the hero.
2. $19 vs. $24 lifetime.
3. Showing the YouTube/DRM limits on the landing page vs. only in the FAQ: measure refund rate, not just sign-ups.
