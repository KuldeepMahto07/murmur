# Funnel analysis

**Status: Not started.** Part of [13 · Analytics](../README.md) in the [Harbor SaaS plan](../../README.md).

| Step | Metric | Target |
|---|---|---|
| Store or site visit → install | Store conversion (dashboard) | ≥ 25% |
| Install → first completed download | Activation (opt-in event) | ≥ 70% within 24 h |
| Install → extension connected | Hand-off success | ≥ 60% |
| First download → sees a Pro feature | Pro exposure | ≥ 30% in 14 days |
| Trial → paid | Trial conversion | 3–5% of all installs, 15% of trial starters |

**Weekly review:** find the biggest drop and ship one fix for it. For example, if extension-connected is low, improve the first-run check that the engine is running.
