# Beta users

**Status: Not started.** Part of [08 · Launch](../README.md) in the [Fetchline SaaS plan](../../README.md).

- **Source:** the waitlist, plus r/DataHoarder, r/software and r/opensource "feedback wanted" threads (follow each sub's self-promotion rules).
- **Onboarding:** a 3-step welcome email: (1) install the app and extension, (2) try the video button on a supported site, (3) reply with your first impression.
- **Reward:** free Pro lifetime for any tester who files 3 useful reports.
- **Tracking:** a GitHub Project board with columns Reported → Reproduced → Fixed → Verified. See [beta-testing](../../07-testing/beta-testing/README.md).
