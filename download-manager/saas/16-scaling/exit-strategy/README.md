# Exit strategy

**Status: Not started.** Part of [16 · Scaling](../README.md) in the [Fetchline SaaS plan](../../README.md).

**Options, in order of fit:**
1. **Lifestyle business:** keep it profitable, small and independent. Fits a lifetime-licence model best.
2. **Sale on an indie marketplace** (Acquire.com and similar) once there is 12+ months of clean revenue history. Utilities like this typically sell for about 3–5× annual profit.
3. **Strategic acquirer:** a security or utility suite, a VPN vendor or a browser maker.
4. **Hand to the community:** if winding down, open-source the Pro module and transfer the store listings so users aren't stranded.

**Keep it sellable from day one:**
- Clean IP. The code is original, there's no IDM code, and the [IDM study](../../01-idea/competitor-analysis/idm-analysis.md) used public docs only.
- Documented systems.
- Revenue only through the merchant of record.
