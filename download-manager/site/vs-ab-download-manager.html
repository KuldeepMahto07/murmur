Harbor and AB Download Manager

AB Download Manager is a mature, free, open-source download manager (Apache-2.0) for Windows, macOS, Linux and Android. You don't have to choose: Harbor's browser extension can send downloads to it.

Connect them

  1. Install and start AB Download Manager (winget install amir1376.ABDownloadManager). Its browser integration listens on port 15151.
  2. Install the Harbor extension, open its popup and choose Send downloads to → AB Download Manager. If you set an API key in AB DM, enter it too.
  3. Hover a video, click Download and choose a quality. AB DM opens its add dialog with the file or stream, including the cookies and referer the site needs.

Harbor uses AB DM's published integration API and doesn't include any of its code. It is not affiliated with the AB Download Manager project.
