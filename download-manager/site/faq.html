Frequently asked questions

Can Harbor download from YouTube, Instagram, Netflix…?

Netflix, Disney+, Prime Video and other DRM-protected services: no, never.

YouTube and Instagram: not with the Chrome Web Store or Edge Add-ons version of the extension, because store policies forbid it. The version distributed directly (GitHub, winget) can use yt-dlp, a separate open-source program you install yourself (winget install yt-dlp.yt-dlp). It then lists the qualities of supported pages.

Downloading from these platforms may break their terms of service. Use it for your own uploads, Creative Commons videos, or with the creator's permission. For your own content, YouTube Studio and Instagram's "Download your information" are the official routes.

The extension says "Harbor is not running"

The extension hands downloads to the Harbor app on your PC. Start it from the Start menu or the tray, or with desktop\Harbor.vbs. Right-click the tray icon to turn on Start with Windows so it's always there. If you changed the port, set the same port in the extension popup.

The button shows "No downloadable stream seen yet"

Play the video for a few seconds: many players only request the stream when playback starts. If the site streams in a protected way, there's nothing Harbor can download.

Windows SmartScreen warns about the installer

Until our code-signing certificate is in place, new unsigned apps get this warning. Every release lists its SHA-256 checksum so you can confirm the file is the one we published.

How is it faster than my browser?

Browsers fetch a file over one connection. Many servers limit speed per connection, so Harbor asks for several parts at once. When a connection finishes, it splits the biggest remaining part again, so all connections stay busy until the end. If a server doesn't allow this, Harbor falls back to one connection.

What happens if my PC crashes or the Wi-Fi drops?

Progress is written to disk every second. After a crash, Harbor resumes downloads on its own when it starts. It first re-reads a small overlap of what it already has and compares it with the server, so a corrupted tail can't slip into your file.

What do the SHA-256 and "matches expected" mean?

Every finished file gets a SHA-256 fingerprint. Many sites (Linux distributions, SDKs, datasets) publish theirs. Paste it in the "Expected checksum" box and Harbor marks the download red if the file doesn't match.

I use AB Download Manager. Can I keep it?

Yes. In the extension popup choose Send downloads to → AB Download Manager. The video button then sends files and streams to AB DM through its own integration API. See Harbor and AB Download Manager.

Does Harbor collect my browsing or downloads?

No. Nothing about your URLs, files or cookies leaves your PC. See the privacy policy.
