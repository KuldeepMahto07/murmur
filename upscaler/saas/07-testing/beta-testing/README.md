# Beta testing

**Status: not started.**

**Plan:**
1. Recruit 20 testers from the waitlist (mix: no-GPU vs GPU, creator vs restorer).
2. Give them the desktop build plus 60 cloud minutes each.
3. Collect issues through an in-app "Report a problem" link that attaches `job.json` and logs.
4. Run a weekly survey: time-to-first-render, satisfaction (1-5), would-pay price.

**Exit criteria:** crash-free renders at least 98%, median rating at least 4, and at least 30% of cloud testers top up.
