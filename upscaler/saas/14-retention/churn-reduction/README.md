# Churn reduction

**Status: Not started (plan written).** Part of [14 · Retention](../README.md) in the [Clarion SaaS plan](../../README.md).

- **Leading indicators:** no render in 14 days, repeated failed jobs, credits unused for 2 cycles.
- **Plays:** pause subscription (1-3 months), downgrade to a credit pack, a "credits roll over 1 month" save offer.
- **Product fixes for the top churn reasons:**
  - "too slow": TensorRT, priority queue
  - "quality not enough": RIFE, Studio models
  - "only needed it once": one-off packs instead of subscriptions
