# Freemium model

**Status: Not started (plan written).** Part of [11 · Conversion](../README.md) in the [Clarion SaaS plan](../../README.md).

- **Free forever (local):** every local feature is unlimited and watermark-free. This is the wedge against Topaz's $59/mo desktop.
- **Free cloud:** 3 credits per month, images up to 16 MP, a queue with lower priority.
- **Paid cloud:** speed (a GPU for people who don't have one), higher resolution caps, priority queue, API.

Reasoning: local rendering costs us nothing, and cloud GPUs are the only marginal cost, so that's where we charge.
