# Sales funnel

```
SEO / social / directories
  → landing page (wipe demo)
  → download (local, free)        or   cloud signup (3 free credits)
  → first render (activation)
  → hits a limit: no GPU / too slow / wants it faster
  → buys a credit pack or subscribes
  → renews / upgrades / refers
```

| Step | Target rate |
|---|---|
| Visit → download or signup | 8% |
| Signup → first render | 60% |
| First render → paid within 30 days | 6% |
| Monthly churn | below 8% |

The upsell trigger in the local app: when the ETA exceeds 10 min, show "Render this in the cloud in about 2 min for N credits".
