# Subscriptions

**Status: Not started (plan written).** Part of [12 · Revenue](../README.md) in the [Clarion SaaS plan](../../README.md).

- **Creator** $12/mo (60 credits) and **Pro** $29/mo (200 credits, priority queue, API key). Prices and margins are in [pricing strategy](../../11-conversion/pricing-strategy/README.md).
- Stripe Billing with customer-portal self-service (upgrade, downgrade, cancel).
- Credits reset monthly; packs bought separately never expire.
- **Revenue goal (month 12):** 400 Creator + 150 Pro gives MRR of about $9.2k. GPU cost at 60% utilisation on 4090-class workers is about $1k, so the gross margin is about 85%.
