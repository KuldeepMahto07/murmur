# Enterprise deals

**Status: Not started (plan written).** Part of [12 · Revenue](../README.md) in the [Clarion SaaS plan](../../README.md).

**Targets:** e-commerce catalogue teams, tape-digitisation businesses, stock-footage sites, newsrooms with archives.

**Offer:**
- An API with an SLA and committed-use pricing ($0.05-0.08 per credit at 50k+ credits a month, viable only on 4090-class or TensorRT workers)
- Dedicated GPU pods
- SSO
- A DPA
- An on-prem Docker worker licence: customers run the open-source models on their own GPUs and pay a per-node fee

**Sales motion:** cold email (stage 09), a 2-week pilot with 2,000 credits, then an annual contract.
